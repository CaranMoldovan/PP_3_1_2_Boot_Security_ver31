# StudyTracker — приложение для контроля учёбы

Android-приложение (Kotlin + Jetpack Compose), которое помогает контролировать учёбу:

- **Предметы** — список ваших учебных предметов с цветовой меткой.
- **Задания** — задачи по предметам с дедлайнами; просроченные подсвечиваются, выполненные отмечаются галочкой.
- **Таймер** — секундомер занятия по выбранному предмету; время сохраняется в историю.
- **Статистика** — общее время занятий, прогресс по заданиям и время по каждому предмету.

Все данные хранятся локально в базе Room — интернет не нужен.

## Стек

| Технология | Использование |
|---|---|
| Kotlin 2.0 | язык |
| Jetpack Compose (Material 3) | интерфейс |
| Room | локальная база данных |
| Navigation Compose | навигация по вкладкам |
| ViewModel + StateFlow | состояние |

Минимальная версия Android — 8.0 (API 26).

## Как собрать и запустить

1. Откройте папку `android-study-tracker` в **Android Studio** (Ladybug или новее).
2. Дождитесь синхронизации Gradle.
3. Запустите конфигурацию `app` на эмуляторе или устройстве.

Либо из командной строки (нужен установленный Android SDK):

```bash
./gradlew :app:assembleDebug
# APK появится в app/build/outputs/apk/debug/app-debug.apk
```

## Структура кода

```
app/src/main/java/com/example/studytracker/
├── MainActivity.kt          # точка входа, нижняя навигация
├── data/
│   ├── Entities.kt          # Subject, StudyTask, StudySession
│   ├── Daos.kt              # запросы к базе
│   └── AppDatabase.kt       # Room database
└── ui/
    ├── StudyViewModel.kt    # состояние приложения и таймер
    ├── theme/Theme.kt       # тема Material 3
    └── screens/             # экраны: предметы, задания, таймер, статистика
```
